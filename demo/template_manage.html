EZ-Deploy Email Template 管理（網頁版）

對應 template_manage.sh 的金鑰驗證、列出、查看、刪除與上傳功能。SITE_KEY 與 API_KEY 只在這個頁面開啟時由你輸入，不會寫進網頁或儲存起來。

🔐 安全說明：此頁面不會把 SITE_KEY / API_KEY 寫死在檔案裡，也不會自動存入瀏覽器。重新整理頁面後需要重新輸入。
⚠️ 關於 CORS：瀏覽器直接呼叫 API 需要 API 伺服器允許跨來源請求。若遇到瀏覽器 CORS 阻擋（Failed to fetch），這是瀏覽器限制，並非金鑰錯誤；可改用 template_manage.sh 做 CLI 測試。

① 憑證設定

輸入 API 連線資訊。對應 .env.local 的 API_BASE / SITE_KEY / API_KEY。

「驗證金鑰有效性」等同 bash template_manage.sh list：第一次執行 data 為空但 code 為 SUCCESS，代表金鑰有效。
